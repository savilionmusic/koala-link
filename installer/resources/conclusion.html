Koala Link is installed

  1. Open Koala Link from Applications and choose MPC Touch or Push 2.
  2. MPC Touch: connect it and install DisplayLink Manager for its screen. If macOS asks, allow Koala Link and mpc_touchd in Privacy & Security › Accessibility.
  3. Push 2 preview: connect and power it by USB before choosing it. Close Ableton Live and quit Paper Cut if it is using the Push. Koala stays in its ordinary Mac window while Koala Link drives the Push display. Physical Push validation is pending.

To remove it: /Library/Application Support/Koala Touch/uninstall.sh in Terminal.
